# 문법 hard-negative 전문가 규칙

## 목표

chosen의 교정·분석 형식을 유지하면서 **명백한 한국어 문법 판단 하나**만 틀린다. 표준 규정상 복수 허용되는 표현이나 학설에 따라 달라지는 분석은 오류 소재로 사용하지 않는다.

## 전문 판단 원칙

- 띄어쓰기: 조사/의존 명사/보조 용언을 구분하고, 원칙과 허용을 혼동하지 않는다.
- 형태·품사: 문맥 속 실제 기능을 기준으로 판단한다. 같은 표면형의 다른 품사를 섞지 않는다.
- 발음·음운: 적용 환경이 명확한 규칙 하나만 대상으로 삼는다.
- 높임·표준 용법: 주체·객체·청자를 구분하고 실제로 허용되는 변이형은 피한다.
- 문장 구조: 안은문장·안긴문장, 절과 구를 서로 다른 단위로 세지 않는다.

## 권장 오류 설계

- 여러 교정 항목 중 정확히 한 항목의 정오 판정만 뒤집는다.
- 한 규칙의 적용 조건 하나만 잘못 설명하고 나머지 예시는 유지한다.
- 예외 목록이면 한 단어만 누락하거나 잘못 포함한다.
- 교정 결과와 설명이 함께 있다면 동일한 한 오개념에서 일관되게 파생되도록 한다.

## 금지

- 붙여쓰기와 띄어쓰기 모두 허용되는 보조 용언처럼 논쟁적·허용적인 사례를 고르지 않는다.
- 두 항목의 답을 맞바꾸거나 여러 교정을 동시에 바꾸지 않는다.
- chosen에도 명백한 문제가 있는 부분을 더 정확하게 고쳐 rejected를 우수하게 만들지 않는다.
- 고의적 오탈자나 비문을 추가해 별도 오류를 만들지 않는다.
- rejected 본문에서 자신이 만든 오류를 설명하지 않는다.

## 출력 전 내부 점검

하나의 표준 규칙으로 rejected의 판단을 명확히 반박할 수 있는지, chosen이 상대적으로 더 타당한지 확인한다. 복수 허용 가능성이 조금이라도 크면 다른 오류를 선택한다. 점검 과정은 출력하지 않는다.
